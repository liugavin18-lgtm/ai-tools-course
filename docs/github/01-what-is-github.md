# GitHub 是什么

## 一句话
**GitHub 是一个放文件的网盘，而且会记住每一次修改。**

和普通网盘的区别：

| | 普通网盘 | GitHub |
|---|---|---|
| 存文件 | 可以 | 可以 |
| 记录每次修改是谁改的、改了什么 | 基本没有 | 完整记录，随时能退回 |
| 多人同时改 | 容易互相覆盖 | 有合并机制 |
| 一键发布成网站 | 不行 | 可以（Pages） |

## 四个必须认识的词

- **仓库（Repository / repo）**：一个项目的文件夹，GitHub 上的基本单位。
- **提交（Commit）**：存一次“存档点”，并写一句说明，比如“补充第二章”。
- **分支（Branch）**：从主线拉出的一条试验线，改坏了不影响主线。
- **Pages**：GitHub 的免费功能，把仓库里的网页文件变成网站。

## 为什么培训内容适合放 GitHub

1. **链接固定**：发给学员的链接不会变，内容更新后学员刷新就能看到新版。
2. **版本可追溯**：误删、改错都能找回。
3. **免费**：公开仓库和 Pages 都不收费。
4. **不用买服务器**：不需要自己运维。

!!! danger "公开仓库的红线"
    公开仓库**全网可见**，包括历史记录。一旦传上去的密码或客户信息，即使后来删掉，在历史里仍然能被翻出来。
    **不要上传**：真实客户姓名/电话/截图、密码、API 密钥、内部报价。

## 小测验

??? question "我把仓库设为公开，但内容里有一张含真实客户名的截图，删掉图片文件就安全了吗？"
    不安全。历史提交里还留着这张图。正确做法是：上传前就脱敏；已经传了要联系懂行的人清理历史，并视情况更换相关密钥。
