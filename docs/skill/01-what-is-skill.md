# Skill 是什么

## 一句话
**Skill 是写给 AI 的“工作说明书”，让它每次都按你的方法做事。**

如果说 MCP 是 AI 的手（能碰到外部工具），Skill 就是 AI 的操作手册（知道该怎么做）。

## 为什么需要 Skill
你有没有遇到过：

- 每次让 AI 写周报，都要重新交代一遍格式和语气？
- 同一类任务，AI 这次做对了，下次又漏了步骤？

Skill 就是把这些要求**写下来存好**，AI 遇到对应场景时自动读取并照做。

## MCP 和 Skill 的区别

| | MCP | Skill |
|---|---|---|
| 解决什么 | AI **能做什么**（连接能力） | AI **该怎么做**（方法和规范） |
| 本质 | 一个可运行的程序 | 一份说明文档 |
| 举例 | 能查数据库 | 查完后按固定格式写成报告 |
| 门槛 | 需要写代码 | 会写文字就行 |

两者经常**搭配使用**：MCP 取数据，Skill 规定怎么分析、怎么出报告。

## 适合做成 Skill 的事
- 有固定步骤的重复工作（周报、客户回访记录、培训总结）
- 有固定格式要求的输出
- 需要遵守的规则和红线（例如“不得出现真实客户信息”）

## 不适合的事
- 一次性的临时任务
- 需要实时连接外部系统才能完成的事（那是 MCP 的工作）
