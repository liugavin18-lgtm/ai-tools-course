# 安装和使用

## 安装一个 MCP 服务
以 Claude Code 为例，一条命令即可：

```bash
claude mcp add 名字 -s user -- 启动命令 参数
```

例如，注册一个叫 `local-db` 的本地服务：

```bash
claude mcp add local-db -s user -- uv run /路径/server.py
```

| 部分 | 含义 |
|---|---|
| `local-db` | 你给它起的名字 |
| `-s user` | 对你这个用户的所有项目都生效 |
| `--` 后面 | 这个服务怎么启动 |

查看已装的服务：

```bash
claude mcp list
```

!!! tip "装好后要新开会话"
    已经在运行的对话不会自动出现新工具，**新开一个会话**才能看到。

## 怎么用
装好后**不需要学任何命令**，直接用自然语言提问：

> 列出我本地有哪些数据库，各自多大？
>
> 查一下订单表最近 7 天的数量。

AI 会自己判断要调用哪个工具、传什么参数，并把结果整理给你。

## 不同 AI 工具的配置差异

| 工具 | 配置方式 |
|---|---|
| Claude Code | `claude mcp add` 命令 |
| 部分其他 AI 命令行工具 | 编辑配置文件里的 `mcpServers` 部分 |

不同工具配置文件的格式大同小异，核心都是三项：**名字、启动命令、参数**。

!!! warning "有的工具需要“先加载再使用”"
    部分 AI 工具对工具做了“按需加载”。如果 AI 说“没有这个工具”，可以在提问里明确要求：“请用 xxx 这个 MCP 查，需要先加载工具”。

## 排错三步
1. 新开会话了吗？
2. 命令能在终端里单独跑起来吗？
3. 路径、环境（如 Python、uv）是否正确？
