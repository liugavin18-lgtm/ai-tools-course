# MCP 是什么

## 一句话
**MCP 是 AI 助手和外部工具之间的“统一插座”。**

AI 本身只会聊天，看不到你电脑里的文件，也连不上你的数据库。MCP 规定了一套标准：工具按这套标准“自我介绍”，AI 就能按你的自然语言去调用它。

## 三个角色

| 角色 | 举例 | 做什么 |
|---|---|---|
| 调度员 | Claude、Kimi 等 AI 助手 | 听懂你的话，决定该用哪个工具 |
| 通话规矩 | MCP | 规定工具怎么介绍自己、怎么被调用 |
| 干活的 | 数据库查询工具、绘图服务、文件工具 | 真正去执行 |

!!! note "常见误解"
    MCP 自己**不做判断**。判断“该用哪个工具”的是 AI；MCP 只是让不同工具都能用同一种方式被 AI 调用。

## 没有 MCP 和有 MCP 的区别

**没有 MCP**：想查数据，你要自己打开软件、写查询、复制结果，再贴给 AI 分析。

**有 MCP**：你说“上个月销售额最高的 5 个产品是什么？”，AI 自己去查，直接给你答案。

## 它能连什么
- 本地数据库、文件夹
- 日历、邮箱、文档
- 云端服务（出图、出视频、客服系统等）
- 你自己写的任何工具

## 安全要点

!!! warning "给 AI 的权限越大，越要小心"
    - **只读优先**：能只读的就不要给写权限。
    - **花钱的操作要设审批**：比如会扣费的生成类工具。
    - **敏感信息不要放进工具描述里**。
