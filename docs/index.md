# AI 工具实战课

这是一套**用大白话**讲清楚的入门课，不要求会编程。学完你能做到：

- 把自己的资料发布成一个**任何人都能打开的网站**（GitHub）
- 让 AI 助手**连上你的数据和工具**，而不只是聊天（MCP）
- 把重复的工作流程**固化成 AI 会照做的说明书**（Skill）

## 怎么学

| 模块 | 解决什么问题 | 建议用时 |
|---|---|---|
| [GitHub 入门](github/01-what-is-github.md) | 内容放哪里、怎么发给学员 | 40 分钟 |
| [MCP 讲解](mcp/01-principles.md) | 从原理到自己做一个、安全、排错，含综合项目和测验（共 8 章） | 6~8 小时 |
| [Skill 讲解](skill/01-what-is-skill.md) | 怎么让 AI 记住你的工作方法 | 30 分钟 |

!!! tip "学习顺序"
    建议按顺序学。GitHub 是基础，MCP 和 Skill 都会用到它。

## 先建立一个整体印象

```
你（说人话）
   │
   ▼
AI 助手 ──读取──▶ Skill（工作方法说明书）
   │
   └──调用──▶ MCP（连接数据库、文件、云服务的“插座”）

内容和成果 ──存放/发布──▶ GitHub
```

- **GitHub**：存放和发布内容的地方
- **MCP**：AI 伸向外部工具的手
- **Skill**：AI 手里的操作手册
